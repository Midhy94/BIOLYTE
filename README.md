# BIOLYTE - Sustainable Energy Solutions & Green EPC Infrastructure

Modern web platform for **BIOLYTE**, an industrial green energy and environmental EPC contractor modeled after Green Gulf Industry Limited. Built with React 18, TypeScript, Tailwind CSS, and Framer Motion.

## Overview

BIOLYTE delivers turnkey engineering, procurement, and construction (EPC) solutions for industrial decarbonization, organic waste-to-energy transformation, and environmental infrastructure across the Kingdom of Saudi Arabia and the Middle East.

### Core Capabilities
- **Biogas & Anaerobic Digestion**: High-yield industrial conversion of organic, agricultural, and municipal waste streams into renewable gas and organic fertilizers.
- **Biomethane & Bio-CNG Upgrading**: 98%+ purity membrane gas separation for national grid injection and clean vehicle fuel.
- **Bio-Hydrogen Production**: Decentralized thermal conversion breaking down organic biomass to produce 50 kg of pure H₂ per ton with zero tar.
- **Bio-Methanol & Marine Fuels**: Lifecycle carbon-neutral green methanol supplying commercial shipping fleets and chemical synthesis.
- **Cogeneration & CHP Systems**: Transforming fermentation gas into baseload industrial electricity and district thermal energy.
- **Water-Free Architectural Pavements & Dust Suppression**: Patented eco-friendly soil binders eliminating 100% of water usage in industrial soil stabilization.

## Tech Stack & Architecture

- **Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS with custom editorial typography scales, hairline borders, and BIOLYTE bespoke color palette (`#D12B81` BIOLYTE Rose, `#0d172a` Deep Navy, `#1e3157` Slate Navy)
- **Motion & Interactions**: Framer Motion for hero slide choreography, sticky header elevation with auto-hide, glassmorphic mega-menus, layout shifts, drawer navigation, and modal dialogues
- **Design Language**: Frosted glassmorphism (`backdrop-blur-2xl`), fully rounded interactive controls (`rounded-full`), and clean Futura PT & Inter typography
- **Icons**: Lucide React + custom BIOLYTE brand vector marks

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Midhy94/BIOLYTE.git

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
